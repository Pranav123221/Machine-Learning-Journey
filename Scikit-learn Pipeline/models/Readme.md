# Scikit-learn Pipelines: From Preprocessing to Prediction

A practical comparison of **Machine Learning workflows with and without Scikit-learn Pipelines**, using the **Titanic Survival Prediction** dataset.

This project focuses on understanding how preprocessing, model training, serialization, and prediction work in both approaches.

## 🎯 Objective

The objective of this project is to understand the difference between:

**Manual ML Workflow**

> Preprocessing → Model Training → Save Components → Load Components → Prediction

and

**Pipeline-Based ML Workflow**

> Preprocessing + Model → Single Pipeline → Save Pipeline → Prediction

The project demonstrates why Scikit-learn Pipelines are useful for creating more consistent, reproducible, and maintainable ML workflows.

## 🔄 Workflow

### 1. Without Scikit-learn Pipeline

The first two notebooks demonstrate the traditional approach.

**Training:**

```text
Training Data
     ↓
Preprocessing
     ↓
Feature Transformation
     ↓
Model Training
     ↓
Save Preprocessors + Model
```

**Prediction:**

```text
New/Test Data
     ↓
Load Preprocessors
     ↓
Apply Same Transformations
     ↓
Load Model
     ↓
Prediction
```

The preprocessing components and model are saved separately as `.pkl` files.

---

### 2. With Scikit-learn Pipeline

The next two notebooks implement the same task using `ColumnTransformer` and `Pipeline`.

**Training:**

```text
Training Data
     ↓
ColumnTransformer
     ↓
Preprocessing
     ↓
ML Model
     ↓
Single Pipeline
     ↓
Save Pipeline
```

**Prediction:**

```text
New/Test Data
     ↓
Load Pipeline
     ↓
Automatic Preprocessing
     ↓
Prediction
```

Instead of managing multiple preprocessing objects and the model separately, the complete workflow is stored in a single Pipeline.

## ⚖️ Without Pipeline vs With Pipeline

| Feature                             | Without Pipeline          | With Pipeline              |
| ----------------------------------- | ------------------------- | -------------------------- |
| Preprocessing                       | Manual                    | Integrated                 |
| Model                               | Separate                  | Integrated                 |
| Serialization                       | Multiple files            | Single Pipeline            |
| Prediction workflow                 | Multiple steps            | Simplified                 |
| Reproducibility                     | More manual management    | Easier to maintain         |
| Risk of preprocessing inconsistency | Higher                    | Lower                      |
| Deployment                          | More components to manage | Easier artifact management |

## 🔑 Key Learning

The biggest takeaway from this project is that **Machine Learning is not only about selecting an algorithm**.

A reliable ML workflow also requires consistent preprocessing, correct handling of training and unseen data, reproducibility, and a clear separation between training and inference.

Scikit-learn Pipelines provide a way to encapsulate preprocessing and model training into a **single reusable workflow**.
